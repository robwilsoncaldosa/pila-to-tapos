# Pila to Tapos

An independent helper (not an official BIR app) for a former freelancer closing her BIR registration. It shows the whole path, every document, and the cost before she leaves home. Every item cites the official BIR text, and `npm run check:content` verifies each quote word for word.

See `devpost/spec.md` for the full plan.

## Run it (laptop only)

```bash
npm install
npm run dev          # http://localhost:3000
```

Open these in separate tabs (use the browser's device toolbar for the phone view):

- http://localhost:3000, in phone view (`/` then `/plan`)
- http://localhost:3000/counter (staff)
- http://localhost:3000/tv (click "Simulan ang TV" once so it may speak)

In the phone-view tab, tick the checklist, then open `http://localhost:3000/join?c=registration`. It does the same thing as scanning the TV's QR code. The queue lives in the server's memory, so restart the server to start again from B-001.

## Run it with a real phone

1. Find the laptop's Wi-Fi address: `ipconfig getifaddr en0` (or check Wi-Fi settings). The phone must be on the same Wi-Fi; a phone hotspot that the laptop joins always works.
2. Put `NEXT_PUBLIC_APP_URL=http://<that-address>:3000` in `.env.local` (see `.env.example`).
3. Start the server on the network: `npm run dev:lan` (allow macOS's "accept incoming connections" prompt). Open `http://<that-address>:3000/tv` on the laptop.
4. On the phone, open `http://<that-address>:3000`, or scan the TV's QR code with its camera.

## Recording the demo

`npm run demo` builds the app and starts it on the network (`next build && next start -H 0.0.0.0`), which is smoother than dev mode for recording. Set `NEXT_PUBLIC_APP_URL` before running it, since the address is baked in at build time.

The TV calls numbers in English ("Number B, zero, zero, one. Registration counter.") using pre-generated clips in `public/audio/`: a whole-call clip for B-001 to B-030, plus word clips for any other number. If a clip is missing, the browser's own English voice reads the line. `NEXT_PUBLIC_SPEECH_MODE=voice` skips the clips.

Other scripts: `npm run build`, `npm run lint`, `npm run typecheck`, `npm test`, `npm run check:content`.

## Pages

- `/` Screen 1, `/plan` Your plan (ticks and answers are saved in this browser only)
- `/join` the QR code's target: checks the checklist, issues a number, and opens `/line`
- `/line` her number, the path, the full-screen "Ikaw na!" when she is called, then "Balik ka sa [date]" after visit 1, the labeled demo switch, visit 2, and "Tapos na!"
- `/counter` the staff screen: waiting list, Call next, Done
- `/tv` the waiting-room TV: the current number, the spoken call, and the QR code
- `/tv/voice-check` lists the browser's voices and test-speaks the call
- `/team` the team edit screen (needs `TEAM_PASSCODE` and `TEAM_COOKIE_SECRET` in `.env.local`): edit steps, documents, fees, and the processing time; every save needs a citation whose quote appears word for word in the official source

The plan lives in `content/plan/bir-closure.json`; the official excerpts it quotes are in `content/sources/`.

## How it was built, credits, and disclosures

- **Built for Devpost's "Build With AI: Basics" hackathon** with the Devpost Learn skill pack. The planning documents it produced are in `devpost/`: scope, PRD, spec, build checklist, and the official-source research. The personal learner profile is kept out of the repository.
- **AI coding assistant:** built with Claude Code (Anthropic). The learner made the product decisions; the assistant wrote and verified most of the code.
- **No live AI in the app:** Magtanong shows pre-written answers that quote the official BIR text, and the app doesn't call any AI service.
- **Voice:** the TV call clips in `public/audio/` and the demo video's narration were generated locally with the open-source Kokoro text-to-speech model (`onnx-community/Kokoro-82M-v1.0-ONNX`, Apache-2.0), voice "Heart" (`af_heart`).
- **Demo video:** recorded from the running app with scripted steps and composed with a local product-video engine. The music is original and royalty-free, generated by that engine.
- **Official sources:** the excerpts in `content/sources/` quote BIR issuances: RMC No. 47-2026, the BIR Citizen's Charter 2026 (entry 28-A), and RMC No. 84-2026. Links are in `content/sources/sources.json`.
- **Not affiliated with the BIR:** Pila to Tapos is an independent helper, and the office and queue in the app are simulated. Check with your Revenue District Office for your own case.
- **Open-source libraries:** Next.js, React, Tailwind CSS, shadcn/ui (Radix UI), lucide-react, and qrcode.react, each under its own license.
